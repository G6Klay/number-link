# 一笔连数

一个可以在浏览器里玩的连数字游戏。n×n 的棋盘上只露出一部分数字，你要从 1 出发，按 1→2→3… 的顺序走遍所有格子，每格只走一次，最后停在 n²。每一步可以走向相邻的 8 个方向（含斜向）。

整个游戏只有一个 HTML 文件，用原生 JavaScript 和 SVG 编写，不需要框架，也不需要构建。

## 开始游戏

下载或克隆仓库后，用浏览器打开 `number-link.html`。也可以把这个文件直接部署到任意静态托管服务上。

字体从 Google Fonts 加载。没有网络时会改用系统字体，不影响游戏功能。

## 玩法

在格子上点按或拖动来连线。带下划线的是题目给出的数字，其余格子的数字要靠推理得出，走过之后才会显示。

| 模式 | 规则 |
| --- | --- |
| 生命模式 | 每走一步都会判断对错，走错扣一颗心，三颗心用完这关失败 |
| 自由模式 | 不判断对错，点回之前走过的格子就能从那里重新规划 |

如果一步本身就违反规则（不挨着上一步、格子上已经写了别的数字、这个数字其实标在别处），只会提示，不扣心。

- **撤销**：退回一步，仅在自由模式下可用，也可以按 `Ctrl + Z`。
- **提示**：每关 3 次。如果已经走偏，会先退回到最后一步正确的位置，再帮你放好下一步。
- **重开**：清空本关的连线、生命、提示次数和计时。
- **选关**：选择难度、模式和已解锁的关卡。

计时从第一步开始，走完全部格子后停止。

## 关卡与难度

一共 30 关，棋盘逐步变大：

| 关卡 | 棋盘 |
| --- | --- |
| 1–3 | 5×5 |
| 4–8 | 6×6 |
| 9–15 | 7×7 |
| 16–24 | 8×8 |
| 25–30 | 9×9 |

同一关在不同难度下是同一条路线，只是给出的数字多少不同：

| 难度 | 给出的数字 |
| --- | --- |
| 大师 | 只给保证唯一解所需的最少数字 |
| 困难 | 在大师的基础上，再补回剩余空格的约 6% |
| 普通 | 补回约 16% |
| 简单 | 补回约 30% |

补回的数字放在相邻两个提示之间间隔最大的地方，所以低难度只是缩短空档，仍然需要推理。每个难度的解锁进度分开记录，保存在浏览器的 localStorage 里。

## 原理

1. **生成路线**：先用带随机扰动的 Warnsdorff 规则走出一条经过所有格子的路线，再做大量 backbite 变换把路线形状打散，避免总是沿着边缘绕圈。
2. **挖去数字**：一开始所有数字都给出，然后按随机顺序逐个尝试拿掉。每拿掉一个就用求解器数一遍解，仍然只有一个解才真正拿掉，否则放回。最后剩下的就是大师难度的数字。
3. **求解器**：从 1 开始回溯搜索，用两条规则剪枝。一是到下一个已知数字的棋盘距离不能超过剩余步数；二是每个还没走到的格子（终点除外）至少要留有两个可用的相邻格，才能一进一出。每次数解都有搜索步数上限，超出上限时保守地保留这个数字，因此每道题都保证只有唯一解。

每一关的随机种子由关卡号决定，所以同一关在任何设备上都是同一道题。生成在 Web Worker 里进行，9×9 大约需要 1～2 秒；生成结果会缓存起来，并在后台提前生成下一关。
